# Discussion themes visual check

A temporary local Next.js route rendered the actual story component with synthetic
article, theme and coverage data. The route and server were removed after review;
no live database or Hacker News data was used.

At CSS widths of 320px and 1280px, light and dark themes, and 100% and 200% root
text size, the document scroll width matched the viewport width. The page showed
one **Discussion themes** heading, three collapsible themes and no legacy intro or
critical/supportive cards. At 320px with 200% text, the first disclosure expanded
and its source-comment popup opened without horizontal overflow.
