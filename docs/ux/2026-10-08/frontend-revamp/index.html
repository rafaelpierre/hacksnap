Where the current UI loses momentum

  • Wide thumbnail-and-excerpt rows leave a large gap between the headline and its metadata. The card’s reading order is harder to scan.
  • Discussion analysis sits inside the story reader, while feed comment counts link directly to Hacker News. The feed does little to signal the analysis already available.
  • On mobile, the full lifetime most-read block precedes the first Latest story. Supporting content delays the main reading task.
  • The small headline scale, multicolored topic treatment, and repeated row composition flatten the hierarchy. Larger, more deliberate type and a tighter color system can make the same content feel more current.

Findings are based on the current frontend source and the repository’s captured UI, not a new live production audit.

What to borrow from the references

From Reddit

  • A clear separation between navigation, the feed, and supporting content.
  • Compact metadata and actions close to the story they describe.
  • A visible discussion entry point that makes the next click easy to understand.
  • A layout that remains useful when a story has no image.

From DEV

  • Headlines that lead the card, with supporting text beneath them.
  • A stronger type scale and generous reading surfaces.
  • Topics that are always visible on desktop and easy to reach on mobile.
  • A supporting story list that gives readers somewhere relevant to go next.
The screenshots also contain search, accounts, posting, following, voting, and saved collections. Those features are outside this redesign. The mocks use the current Hacksnap capabilities.

For a smaller corpus, keep the feed finite, preserve text-only stories, and let related stories and the existing most-read list provide the next step. Large promotion billboards, oversized image slots, and long secondary navigation lists would consume space without improving the reading path.

Design decisions

Concept A

Rust marks the current navigation and key discussion action without coloring every surface. Sans-serif titles support fast scanning. Firmer icons make the compact navigation easier to parse. Flat cards and tighter spacing keep several stories visible together.

Concept B

Indigo distinguishes reading actions and selection states. Bricolage adds a stronger headline voice. Generous inner spacing separates the story, takeaway, and actions. Lighter squared icons support labels. White cards define reading units against a quiet neutral surface.

Both keep imagery optional, use the existing product wordmark as text, and make story briefs and discussion analysis the product’s repeated visual motif. The feed, story detail, and related-story list share the same system in each mock.
