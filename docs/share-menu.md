# Share dialog destinations

The reusable Share dialog is available on feed rows and at both story-page Share actions. Copy link always uses the canonical story address, using its saved slug or numeric ID. The suggested post starts from the headline and takeaway; pending summaries get a complete readable draft. Readers can edit the post before copying or opening a text-capable destination.

The initial destinations are X, LinkedIn and Email. X and Email receive the current edited text. The dialog uses the official twitter-text weighted count, including URL transformation, to prevent opening X when the draft exceeds 280 characters; readers can shorten the draft without changing the text available for copying or Email. LinkedIn’s share endpoint accepts only a URL and cannot prefill the draft text. Clicking LinkedIn first copies the edited post, adding the canonical story URL if it is missing, then shows an Open LinkedIn link and instructions to paste. If copying fails, the selected manual-copy field includes both the draft and URL. LinkedIn opens only on that second click, keeping navigation within a fresh user gesture and giving readers a chance to copy before leaving. Its preview receives the canonical URL; pasted text retains that URL even if LinkedIn cannot render a preview. Editing or resetting a draft clears the prepared LinkedIn step. Opening a destination is navigation to a compose/share surface, not a publication confirmation.

The feed initially mounts a small Share trigger. Opening it loads the post editor and X parser on demand; the first-open loading state still offers Copy link, LinkedIn, Email, and Copy suggested post. If the editor fails to load, those options remain available and the dialog offers a retry. Closing and reopening keeps any edits to the draft while the story component remains mounted.

If clipboard writing fails or is unavailable, the dialog exposes the exact requested link or post in a selected, read-only field for manual copying. Success feedback appears only after the write resolves.

The native modal dialog is labeled “Share this story” and identifies the selected headline. Background content stays inert while it is open, keyboard focus stays inside, and Escape, the close button, or the backdrop dismisses it and returns focus to Share. Its scrollable panel keeps the draft and manual-copy fields reachable on small screens. The draft is shown before copy and destination actions.
